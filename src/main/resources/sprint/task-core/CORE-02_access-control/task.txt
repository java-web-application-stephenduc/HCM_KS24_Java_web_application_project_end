## ═══════════════════════════════════════════
## MỤC TIÊU
## ═══════════════════════════════════════════
Phân tách không gian URL theo role. 
Student không vào được /lecturer/** và /admin/**.
Lecturer không vào được /admin/**.
Admin có thể vào /admin/**.

## ═══════════════════════════════════════════
## URL MAPPING THEO ROLE
## ═══════════════════════════════════════════

PUBLIC (không cần login):
  /auth/**           ← login, register
  /css/**, /js/**    ← static resources

STUDENT only:
  /student/**        ← dashboard, booking, history, profile

LECTURER only:
  /lecturer/**       ← queue, evaluation form, equipment assignment

ADMIN only:
  /admin/**          ← equipment CRUD, dispatch confirmation, seed data views

SHARED (bất kỳ role đã login):
  /dashboard         ← redirect tùy role sau khi login
  /profile/**        ← xem/sửa profile cá nhân

## ═══════════════════════════════════════════
## FILES CẦN TẠO / SỬA
## ═══════════════════════════════════════════

config/SecurityConfig.java
  → Cập nhật authorizeHttpRequests() theo URL mapping trên

config/CustomAuthSuccessHandler.java   ← NEW
  → implements AuthenticationSuccessHandler
  → Sau login thành công, đọc role và redirect về đúng dashboard:
      STUDENT  → /student/dashboard
      LECTURER → /lecturer/dashboard
      ADMIN    → /admin/dashboard

## ═══════════════════════════════════════════
## LOGIC CUSTOM SUCCESS HANDLER
## ═══════════════════════════════════════════

@Component
public class CustomAuthSuccessHandler implements AuthenticationSuccessHandler {
    @Override
    public void onAuthenticationSuccess(HttpServletRequest req,
                                         HttpServletResponse res,
                                         Authentication auth) throws IOException {
        String role = auth.getAuthorities().stream()
            .map(GrantedAuthority::getAuthority)
            .findFirst().orElse("ROLE_STUDENT");

        String redirectUrl = switch (role) {
            case "ROLE_ADMIN"    -> "/admin/dashboard";
            case "ROLE_LECTURER" -> "/lecturer/dashboard";
            default              -> "/student/dashboard";
        };
        res.sendRedirect(req.getContextPath() + redirectUrl);
    }
}
