## DATABASE
## ═══════════════════════════════════════════

CREATE TABLE equipments (
    id                 BIGINT AUTO_INCREMENT PRIMARY KEY,
    name               VARCHAR(200) NOT NULL,
    description        TEXT,
    category           VARCHAR(100),
    quantity_total     INT NOT NULL DEFAULT 0,
    quantity_available INT NOT NULL DEFAULT 0,
    created_at         DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at         DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

## ═══════════════════════════════════════════
## LOGIC CỤ THỂ
## ═══════════════════════════════════════════

[DELETE — Soft delete]
KHÔNG xóa vật lý nếu thiết bị đang có trong borrowing_details với status PENDING/DISPATCHED.
Kiểm tra: borrowingDetailRepo.existsByEquipmentIdAndActiveStatus(id) → throw nếu true
Nếu OK → xóa hoặc đánh dấu deleted=true (thêm cột deleted BOOLEAN)

[UPDATE quantityTotal]
Khi admin cập nhật quantity_total:
  quantity_available += (newTotal - oldTotal)
  quantity_available = MAX(0, quantity_available)  ← không cho âm

[SEARCH]
GET /admin/equipment?keyword=arduino → filter theo tên, trả về filtered list
Dùng @RequestParam(required=false) String keyword trong controller.
