# Mức độ: BẮT BUỘC | Phụ thuộc: CORE-01, CORE-02

## ═══════════════════════════════════════════
## MỤC TIÊU
## ═══════════════════════════════════════════
Mỗi user (Student, Lecturer, Admin) có thể xem và cập nhật thông tin
cá nhân của mình. Lecturer có thêm thông tin chuyên môn (khoa, chức danh).

## ═══════════════════════════════════════════
## DATABASE
## ═══════════════════════════════════════════

Dùng lại bảng user_profiles từ CORE-01.
Bổ sung bảng lecturers (nếu chưa tạo):

CREATE TABLE lecturers (
    id            BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id       BIGINT NOT NULL UNIQUE,
    department_id BIGINT NOT NULL,
    title         VARCHAR(100),   -- "TS.", "ThS.", "GVC."
    bio           TEXT,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (department_id) REFERENCES departments(id)
);

CREATE TABLE departments (
    id   BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(150) NOT NULL,
    code VARCHAR(20)  NOT NULL UNIQUE
);

## ═══════════════════════════════════════════
## LOGIC CỤ THỂ
## ═══════════════════════════════════════════

[GET /profile]
1. Lấy email từ SecurityContext (Authentication.getName())
2. findByEmail → User entity
3. Load UserProfile theo user_id
4. Nếu role == LECTURER → cũng load Lecturer entity
5. Map sang DTO, đưa vào model → render view

[POST /profile/update]
1. Nhận ProfileUpdateDto
2. Validate (fullName không rỗng, phone format)
3. Cập nhật UserProfile, save
4. Nếu là LECTURER → cũng update Lecturer entity
5. Flash message thành công → redirect /profile
