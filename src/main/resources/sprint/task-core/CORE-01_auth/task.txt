## ═══════════════════════════════════════════
## MỤC TIÊU
## ═══════════════════════════════════════════
Cho phép người dùng tạo tài khoản và đăng nhập an toàn.
Mật khẩu PHẢI được hash bằng BCrypt trước khi lưu DB.

## ═══════════════════════════════════════════
## DATABASE — BẢNG CẦN TẠO
## ═══════════════════════════════════════════

CREATE TABLE users (
    id            BIGINT AUTO_INCREMENT PRIMARY KEY,
    email         VARCHAR(100) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    role          ENUM('STUDENT','LECTURER','ADMIN') NOT NULL DEFAULT 'STUDENT',
    active        BOOLEAN NOT NULL DEFAULT TRUE,
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE user_profiles (
    id         BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id    BIGINT NOT NULL UNIQUE,
    full_name  VARCHAR(150) NOT NULL,
    phone      VARCHAR(20),
    avatar_url VARCHAR(500),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

## ═══════════════════════════════════════════
## LOGIC CỤ THỂ
## ═══════════════════════════════════════════

[AuthService.register(RegisterDto dto)]
1. Kiểm tra email chưa tồn tại → throw DuplicateEmailException nếu đã có
2. Validate password == confirmPassword
3. Tạo User entity: email, BCrypt.encode(password), role = STUDENT, active = true
4. Save user → lấy id
5. Tạo UserProfile entity với user_id → save
6. Return void (redirect to login)

[CustomUserDetailsService.loadUserByUsername(String email)]
1. Gọi userRepo.findByEmail(email).orElseThrow(UsernameNotFoundException)
2. Kiểm tra user.isActive() → throw DisabledException nếu false
3. Return new org.springframework.security.core.userdetails.User(
     email,
     passwordHash,
     List.of(new SimpleGrantedAuthority("ROLE_" + user.getRole().name()))
   )

[SecurityConfig]
- loginPage("/auth/login")
- loginProcessingUrl("/auth/login") — Spring Security xử lý POST tự động
- defaultSuccessUrl → redirect tùy role (dùng AuthenticationSuccessHandler)
- failureUrl("/auth/login?error=true")
- logout → /auth/logout → redirect /auth/login?logout=true
