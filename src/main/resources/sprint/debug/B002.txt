CRITICAL BUGS
----------------------------------------------------------------------

1. [TEMPLATE] Wrong sec namespace in 3 dashboard templates
   Files:
     src/main/resources/templates/student/dashboard.html:4
     src/main/resources/templates/lecturer/dashboard.html:4
     src/main/resources/templates/admin/dashboard.html:4
   Issue: xmlns:sec="http://www.w3.org/1999/xhtml"
          -> Must be: xmlns:sec="http://www.thymeleaf.org/extras/springsecurity6"
   Impact: sec:authentication="name" fails silently -> username never renders
           in lecturer/dashboard.html:10 and admin/dashboard.html:10.

2. [ENTITY] Missing cascade on @OneToMany in BorrowingRecord
   File: src/main/java/com/rikkei/salsp/entity/BorrowingRecord.java:49
   Issue: @OneToMany(mappedBy = "record") missing cascade = CascadeType.ALL
          and orphanRemoval = true
   Impact: Saving BorrowingRecord with details causes TransientObjectException.
          Deleting a record fails due to FK constraint on borrowing_details.

3. [ENTITY] Missing cascade on @OneToOne in User
   File: src/main/java/com/rikkei/salsp/entity/User.java:49-50
   Issue: @OneToOne(mappedBy = "user") missing cascade = CascadeType.ALL
   Impact: Deleting a User fails due to FK constraint on user_profiles.

4. [ENTITY] Missing @Column on BorrowingDetail.quantity
   File: src/main/java/com/rikkei/salsp/entity/BorrowingDetail.java:37
   Issue: private int quantity; has NO @Column(nullable = false)
   Impact: JPA generates column as nullable for a primitive int (schema mismatch).

----------------------------------------------------------------------
HIGH SEVERITY BUGS
----------------------------------------------------------------------

5. [CONTROLLER] Missing @ModelAttribute on EquipmentDto
   File: src/main/java/com/rikkei/salsp/controller/AdminEquipmentController.java:62, 97
   Issue: @Valid EquipmentDto dto lacks @ModelAttribute("equipment")
          GET handler adds "equipment" but POST uses derived name "equipmentDto"
   Impact: On validation failure, template expects ${equipment} but gets
          "equipmentDto" -> 500 error.

6. [CONTROLLER] Unhandled DateTimeParseException
   File: src/main/java/com/rikkei/salsp/controller/StudentBookingController.java:84
   Issue: LocalDate.parse(date) throws DateTimeParseException for invalid date.
          Not caught -> HTTP 500 with stack trace exposed to client.
   Fix: Use @RequestParam @DateTimeFormat(iso = DateTimeFormat.ISO.DATE) LocalDate date

7. [TEMPLATE] th:errors swallows child elements in register.html
   File: src/main/resources/templates/auth/register.html:40-42, 48-50, 56-58, 65-67, 72-74
   Issue: th:errors="*{field}" replaces entire <p> body -> error icon spans are
          dead code and never render.
   Fix: Use th:if + th:text instead of th:errors.

8. [TEMPLATE] #fields.errors() should be #fields.globalErrors()
   File: src/main/resources/templates/auth/register.html:81
   Issue: #fields.errors() returns ALL errors (field+global), duplicating
          field errors inside the global error block.
   Fix: Change to #fields.globalErrors()

9. [TEMPLATE] Form action bypasses URL processor
   File: src/main/resources/templates/admin/equipment/form.html:17
   Issue: th:action uses string concat instead of @{...} expression
          '/admin/equipment/' + equipment.id + '/edit'
   Impact: Context path NOT prepended, URL encoding NOT applied.
   Fix: Use @{/admin/equipment/{id}/edit(id=${equipment.id})}

10. [SERVICE] Missing role verification for lecturerId in createBooking
    File: src/main/java/com/rikkei/salsp/service/BookingService.java:104
    Issue: userRepository.findById(lecturerId) loads ANY user regardless of role.
           A student ID passed as lecturerId creates a session where student
           is set as "lecturer".
    Fix: Verify lecturer.getRole() == UserRole.LECTURER (and student's role too).

11. [SERVICE] Missing pessimistic lock in returnEquipment (lost update)
    File: src/main/java/com/rikkei/salsp/service/DispatchService.java:107
    Issue: equipmentRepository.findById() with no lock. Two concurrent calls
           both read the same quantityAvailable, then both increment -> lost update.
    Fix: Use equipmentRepository.findByIdWithLock() as already done in dispatchEquipment.

12. [SERVICE] Missing pessimistic lock in EquipmentService.update()
    File: src/main/java/com/rikkei/salsp/service/EquipmentService.java:64-82
    Issue: equipmentRepository.findById(id) with no lock. Two admins updating
           the same equipment concurrently -> lost update.
    Fix: Use findByIdWithLock or @Version for optimistic locking.

13. [SERVICE] TOCTOU race condition in EvaluationService
    File: src/main/java/com/rikkei/salsp/service/EvaluationService.java:96-98
    Issue: existsBySessionId check without locking. Two concurrent calls can
           both pass the check and create duplicate evaluations.
    Fix: Use @Lock(PESSIMISTIC_WRITE) on the session entity.

14. [SERVICE] Silent inventory cap masks data corruption in returnEquipment
    File: src/main/java/com/rikkei/salsp/service/DispatchService.java:109-112
    Issue: If returned quantity > quantityTotal, surplus is silently zeroed.
           Should throw exception to alert operator.
    Fix: Remove silent clamping; throw BusinessException on data inconsistency.

15. [SERVICE] Orphan BorrowingRecord created with no equipment items
    File: src/main/java/com/rikkei/salsp/service/EvaluationService.java:109-112
    Issue: BorrowingRecord with PENDING_DISPATCH always created, even when
           equipment list is empty -> orphan dispatch queue entries.
    Fix: Only create BorrowingRecord if !details.isEmpty().

16. [CONTROLLER] Potential NPE from authentication.getName()
    Files (multiple):
      src/main/java/com/rikkei/salsp/controller/DashboardController.java:32
      src/main/java/com/rikkei/salsp/controller/LecturerController.java:36,50,77,82
      src/main/java/com/rikkei/salsp/controller/ProfileController.java:37,88
      src/main/java/com/rikkei/salsp/controller/StudentHistoryController.java:24,31
    Issue: Authentication.getName() can return null per Spring Security API.
           No null check before passing to userRepository.findByEmail().
    Fix: Add authentication == null || getName() == null guard.

17. [CONTROLLER] Inconsistent exception handling (SlotConflictException not caught)
    File: src/main/java/com/rikkei/salsp/controller/StudentBookingController.java:107-111
    Issue: Catches BusinessException inline but SlotConflictException falls
           through to global handler with redirect. Mix of inline errors + redirects.
    Fix: Also catch SlotConflictException (after fixing its hierarchy).

18. [SERVICE] Boundary inconsistency: cancellation time check
    Files:
      src/main/java/com/rikkei/salsp/service/CancellationService.java:39
      src/main/java/com/rikkei/salsp/service/StudentHistoryService.java:115
    Issue: CancellationService uses >= (isBefore + hours), HistoryService uses >
           (isBefore). When sessionTime == now+24h, UI says "not cancellable"
           but server allows it.
    Fix: Align both to use the same boundary logic.

19. [SERVICE] N+1 queries in multiple services
    Files:
      src/main/java/com/rikkei/salsp/service/DispatchService.java:47-60
      src/main/java/com/rikkei/salsp/service/EvaluationService.java:63-80
      src/main/java/com/rikkei/salsp/service/ProfileService.java:42-43
      src/main/java/com/rikkei/salsp/service/StudentDashboardService.java:64-68
    Issue: Missing JOIN FETCH on lazy associations triggers additional queries.
           e.g., DispatchService.getDispatchDetail() triggers ~9 queries for 3 items.
    Fix: Add JOIN FETCH to repository queries for eagerly needed associations.

20. [CONTROLLER] Redundant duplicate DB calls in ProfileController
    File: src/main/java/com/rikkei/salsp/controller/ProfileController.java:66-67
    Issue: profileService.getProfileByUserId(user.getId()) called TWICE.
    Fix: Store result in local variable and reuse.

21. [REPOSITORY] Native queries may return duplicate rows per session
    File: src/main/java/com/rikkei/salsp/repository/MentoringSessionRepository.java:53-81
    Issue: LEFT JOIN on borrowing_details produces one row per equipment item,
           duplicating session/lecturer/evaluation data.
    Fix: Add DISTINCT or split into two queries.

22. [TEMPLATE] Missing hidden sentinel for unchecked checkboxes
    File: src/main/resources/templates/lecturer/evaluation-form.html:74-75
    Issue: No _ prefix hidden field before checkbox -> unchecked items not
           bound to empty/false value.
    Fix: Add <input type="hidden" th:name="|_equipmentItems[${stat.index}].selected|" value="on" />

23. [TEMPLATE] Potential NPE from record.status.name()
    Files:
      src/main/resources/templates/admin/dispatch/queue.html:45-47
      src/main/resources/templates/lecturer/queue.html:43-46
      src/main/resources/templates/admin/dispatch/detail.html:25-27
    Issue: .name() on nullable enum field -> NPE if status is null.
    Fix: Add record.status != null check before .name().

24. [EXCEPTION] Inconsistent exception hierarchy
    Files:
      src/main/java/com/rikkei/salsp/exception/InsufficientStockException.java:3
      src/main/java/com/rikkei/salsp/exception/SlotConflictException.java:3
    Issue: Extend RuntimeException instead of BusinessException.
           GlobalExceptionHandler catches them as RuntimeException (too broad).
    Fix: Change to extends BusinessException for consistency.

25. [CONFIG] CustomAuthSuccessHandler assumes single-authority users
    File: src/main/java/com/rikkei/salsp/config/CustomAuthSuccessHandler.java:19-22
    Issue: .findFirst() on authorities assumes exactly one role.
           Undefined behavior if user has multiple roles (e.g., ADMIN + LECTURER).
    Fix: Use priority-based routing (check for ADMIN first, then LECTURER, etc.).

26. [CONFIG] DataSeeder doesn't recreate missing profiles
    File: src/main/java/com/rikkei/salsp/config/DataSeeder.java:96-116
    Issue: When user exists but profile was deleted, profile is never re-created.
    Fix: Check profile existence and create if missing.

    File: src/main/java/com/rikkei/salsp/service/EquipmentService.java:74-79

    File: src/main/java/com/rikkei/salsp/service/BookingService.java:91-92

    File: src/main/java/com/rikkei/salsp/service/EvaluationService.java:121
    Issue: getReferenceById returns proxy; error surfaces at flush time
           (after previous saves already flushed).
    Fix: Use findById().orElseThrow() for fail-fast.

34. [REPOSITORY] JOIN FETCH br.details d is INNER JOIN
    File: src/main/java/com/rikkei/salsp/repository/BorrowingRecordRepository.java
    Issue: INNER JOIN silently drops records without details.
    Fix: Use LEFT JOIN FETCH for robustness.
